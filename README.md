# KQL-threat-hunting-queries
This repository is an effort to provide ready-made detection and hunting queries (and more) in order to help analysts and threat hunters harness the power of KQL in Microsoft Sentinel and Microsoft Defender XDR.

## Structure

- [`Sentinel-KQL/`](Sentinel-KQL) — queries for Microsoft Sentinel tables
- [`Defender-KQL/`](Defender-KQL) — queries for Microsoft Defender XDR advanced hunting tables

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the file naming and header conventions used across queries.
